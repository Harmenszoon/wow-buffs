# Harmenszoon's Buffs

Track a buff or temporary weapon enchant by **Alt-clicking** its icon on Blizzard's buff bar. When it is missing or close to expiring, a reminder appears near the center of the screen. Your choices are saved per character in WoW Forever.

- **Left-click** a spell reminder to cast that buff on yourself if you know the spell.
- **Alt-click** the buff or its reminder to stop tracking it.
- **Alt-drag** a reminder to move the whole row.

The row hides in combat and while you're dead. Reminders resume when the game allows the aura to be read again.

## Installation

In WowUp, select **Get Addons**, then **Install from URL**, and paste this repository's address. [Repository URL](https://github.com/Harmenszoon/wow-buffs)

For manual installation, extract the `-forever.zip` release asset into `_forever_/Interface/AddOns/` so it contains `Buffs/Buffs.toc`. [Download the latest release](https://github.com/Harmenszoon/wow-buffs/releases/latest)
